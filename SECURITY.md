# Security

This repository contains website source and project documentation. Production credentials, private business records and contact submissions do not belong here.

Use GitHub's private vulnerability reporting when available. Do not include credential values, private records or exploit details in public issues.

Before publication, review tracked files, run the publishing check, and scan the full Git history with Gitleaks. If a credential is exposed, revoke or rotate it immediately; deleting a file does not invalidate the credential.
